# V1.6 原生迭代与验收

日期：2026-09-10。设计基准：[V1.6 定稿原型](../prototype/v1.6/留白-v1.6-定稿.html)。

## 已实现

- 菜单栏任务与列表顺序解耦：先启动者先显示，当前任务停止后接替为本轮最早启动的其他运行任务；无运行任务显示留白。手动指定仅接受运行任务，不移动列表位置。
- 名称区拖动排序，无把手和焦点边框。超过 5px 后启动；源卡片降低透明度，目标显示插入线；松手提交，取消不写入顺序。名称区可通过上下方向键调整任务位置。
- 每个任务独立提醒强度，默认轻提醒，A 铃铛按钮按三档循环，位于菜单栏指定与删除之间。设置页等级只用于预览。
- 新建卡片说明跟随单任务提醒规则；开始、暂停、完成的辅助文案与原型一致。
- 保留原生通知授权、退出、离开期间轻提醒汇总及多屏提醒能力，不加入原型的方案比较面板。

## 数据迁移

保存格式从 1 升至 2；新增任务提醒等级、本轮运行序号、菜单栏当前任务 ID。旧任务继承旧全局提醒等级，新建任务始终默认轻提醒。设置页保存的是预览等级，不作用于任务。

首次改写旧版文件前复制为 `state.json.v1-backup`，不覆盖已有备份。若备份或保存失败，显示错误；损坏和未知版本文件保持原有禁止覆盖保护。旧运行任务缺少启动序号时按原顺序补齐。

## 自动验证

12 项 XCTest 全部通过，使用临时文件。覆盖：

- 菜单栏空状态、先启动、不抢占、手动指定、暂停／重置／删除／完成接替、继续不抢回、排序隔离、重开恢复。
- 旧格式迁移、原提醒配置保留、原文件备份、新任务默认轻提醒、任务等级循环、预览与任务隔离。
- 同批任务按各自强度路由，恢复汇总强制轻提醒，预览不修改任务。
- 无效排序目标、首尾键盘边界、排序保存，以及原有暂停恢复、完成去重、损坏保护、改色删除与延长测试。

## 原生界面实测

使用独立 bundle ID 的预览应用与 `/tmp` 演示数据进行功能操作，通过原生应用工具而非 HTML 浏览器访问。

已实测：

1. 首个启动任务进入菜单栏，第二项启动不抢占。
2. 手动指定第二项，原任务停止／暂停后正确接替。
3. 单任务铃铛点击切换，未改变其他任务。
4. 名称区键盘排序与鼠标拖动实际改变顺序；菜单栏任务保持不变。
5. 原位新建表单显示，保存输入的任务名称，任务待开始并默认轻提醒。
6. 设置页独立预览选择、醒目提醒窗口、Esc 退出预览。
7. 已查看原生任务面板和新建卡片截图；没有把手图标或名称区焦点边框。

拖动初测发现自定义粘贴板类型不能被 SwiftUI 接收，已修正为原生兼容类型；接收仍要求当前本地排序会话，外部文本不会触发任务排序。修正后鼠标拖动实测通过。

预览应用由系统重新启动时可能不继承环境变量，已补充 Debug 预览包固定数据路径；Release 不读取预览路径。临时拖动诊断输出已从源码移除。
