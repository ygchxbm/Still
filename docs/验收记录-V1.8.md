# v1.8 原生实现与验收

依据：[v1.8 定稿与迭代](../prototype/v1.8/版本迭代.md)。本次不包含新的轻提醒设计及登录自启。

## 已实现

- 完成提醒加时进入独立 300 秒阶段，originalDuration 保存原定时长。重复加时保持原定值；重置及完成后再来恢复原定值。
- 任务卡显示加时中／加时已暂停／加时完成、原定与加时时长及本阶段进度。没有新增任务卡加时按钮。
- 无运行任务菜单栏显示选定 5 号线条猫，使用透明 AppKit 模板图像，供系统处理菜单栏明暗与高亮。
- 保留原生轻提醒的「到时了」交替、面板摘要和无声系统通知。待确认且无运行任务时在猫与提醒文字间交替，预留固定宽度；无任务不绘制进度条。
- 胶囊沿用仅全屏且有运行任务时显示的条件。

## 数据兼容

新增可选 originalDuration 字段；旧数据缺失该字段仍可读取。当前 duration 表示本计时阶段时长。重置和再来清除原始时长备份。旧版已经被覆盖成 5 分钟的数据无法推断原始时长，不补造恢复。

## 验证

2026-09-24：`swift test` 通过，17 项测试、0 失败。新增覆盖原始时长保留、加时进度、暂停后保存恢复、重复完成加时、再来／重置、旧任务解码、模板图像生成。测试使用临时状态文件，不接触用户任务。

待实机验收：浅深菜单栏背景及高亮、猫图标小尺寸辨识度、完成通知与轻提醒交替、原生加时界面、跨 Space 与多屏。测试通过不等于这些场景已验收。

## 后续原生调整（2026-09-24，用户明确授权）

以下更新覆盖本文初始实现中“保留轻提醒三处提示”的描述，不修改已冻结的 v1.8 HTML 定稿：

- 轻提醒仅发送无声系统通知；删除菜单栏「到时了」交替提示、面板完成摘要及确认按钮。任务卡完成状态不变，通知点击仍打开面板。未允许通知时不提供额外提醒兜底，设置页说明轻提醒无法显示。
- 设置新增「登录时自动启动」，通过 SMAppService.mainApp 注册／注销。以系统状态为准，不新增本地布尔偏好，不在首次启动时自动注册。需要批准时提供系统登录项设置入口，失败时显示错误且恢复实际状态；设置页出现及应用重新激活时刷新状态。
- 正常应用启动只驻留菜单栏；保留仅用于隔离开发预览的 DEBUG 自动打开面板路径。
- 最低系统版本保持 macOS 14。实际注销登录后的自启、系统批准流程及当前本地临时签名下的注册行为尚待实机验收；未替用户开启登录项。

后续调整验证：`swift test` 共 19 项通过，0 失败；新增登录项默认不注册、待批准、外部状态刷新、注销及失败后状态回读测试。测试使用注入的系统服务替身，不修改真实登录项。

## 弹窗定位修订：方案 B

用户确认显示期间固定弹窗位置。打开时按菜单栏／胶囊入口定位；每秒刷新不再按菜单栏中心重定位。仅内容尺寸变化时调整窗口大小，保持左边缘与顶部不动，避免设置页或任务数量变化造成裁切；关闭后再次打开重新定位。箭头不单独跟随菜单栏移动。真实图标／计时切换视觉仍待实机验收。
