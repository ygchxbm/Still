# Still 功能与区域命名表

版本：v2 · 2026-09-09。**唯一界面基准：[当前 HTML 原型](../prototype/留白-未定稿工作副本.html)**。本表用于沟通、需求和验收；统一称“任务”，保留原型可见文案中的“倒计时”。

配套：[界面命名图](界面命名图.html)。图中嵌入本次原型源码快照，可实际操作并定位元素，非手绘结构图。文档演示使用独立存储键，不修改原型或原生应用数据。

## 如何描述修改

建议写：**任务实例 + 编号／固定名称 + 修改内容 + 触发状态**。例如：“任务‘专注工作’的 C23 计时主按钮，在暂停状态下增大点击范围。”

- 已有编号保持不变；原型不存在的原生项标为“保留编号”，不显示为当前功能；新增项追加编号。
- C 类编号描述控件类型，多张任务卡片共用。指定实例时加任务名；同名再加列表位置。命名图默认定位第一张任务卡片。
- E05/E09 表示原样配色行的第一个预览色点；其他行同理。C10–C14 是可点击的任务色位按钮，E09–E13 仅展示颜色。
- 同一控件的状态文案不增加编号：C23 为开始／暂停／继续／再来；F16 为知道了，完成／结束预览。
- 样式层也可有编号：边框、底色、尖角、刻度可能由 CSS 或伪元素实现；命名图高亮其所属容器，并非独立按钮。
- 没有被默认流程展示的历史创建方案、隐藏手动选色区、隐藏键盘说明，以及旧布局代码，不列为当前功能。

## 与 v1 的关键差异

| 项目 | 以当前原型为准 |
|---|---|
| 菜单栏 | 页面模拟；无右键菜单，无“到时了”交替文本 |
| 新建表单 | 名称标签为“01 / 任务名称”；可留空；无效时长在提交时拦截，不禁用确认按钮 |
| 设置页 | 无系统通知授权和退出按钮；配色用行选中样式，无勾号 |
| 轻提醒 | F20 右上角浮层；无原生面板摘要条或系统通知 |
| 提醒内容 | 时钟字符、单任务名称和引导语；预览也显示延长按钮，点击不改变任务 |
| 数据恢复 | 浏览器存储与页面可见性逻辑，不等同原生文件恢复及多屏提醒 |

## 任务状态

| 固定名称 | 原型状态值 | 主按钮文案 | 计时辅助文本 |
|---|---|---|---|
| 待开始 | ready | 开始 | 点击开始计时 |
| 正在计时 | running | 暂停 | 已专注 MM:SS |
| 已暂停 | paused | 继续 | 时间已冻结 |
| 已完成 | done | 再来 | 计时结束 |

新建确认与重置进入待开始；延长 5 分钟改变总时长，因此随后重置恢复的是 5 分钟。首次演示数据包含运行与暂停任务。
