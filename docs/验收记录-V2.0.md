# v2.0 原生实现与验收记录

日期：2026-11-19。开发依据：[v2.0 定稿](../prototype/v2.0/留白-v2.0-定稿.html)及[版本迭代](../prototype/v2.0/版本迭代.md)，用户明确确认 1:B、2:B。

## 实现

- 设置页采用固定主标题栏：左侧返回倒计时、中间设置、右侧收起，移除内容区重复的行内返回。
- 新建任务增加直接填写的到期提示、默认文案、80 UTF-16 单位计数、恢复默认和醒目提醒预览。原生限制保留完整字符。
- 任务独立保存 completionMessage；旧任务无字段、留空或纯空白时使用默认提示。继续保留 version 2 存储格式，现有数据无需迁移。
- 三档正式提醒、设置预览和单任务恢复摘要读取任务提示；多任务恢复使用默认提示。加时、重置、再次开始及重开保留字段。
- 表单预览通过独立临时任务与醒目提醒事件呈现，不向任务列表或正式文件保存，不改变设置页预览档位。长提示或多次换行使用可滚动的提示区域。

## 原生目视验收限制

已用独立 bundle ID 与 Debug 专用临时数据路径启动测试应用，未替换安装应用或读写正式任务数据。电脑使用工具连续返回 ScreenCaptureKit 屏幕捕获错误（SCStreamErrorDomain -3811），无法读取原生界面，测试应用已清理退出。因此，本轮不认定原生顶栏、表单布局、原生提醒窗口以及预览 Esc 的实机目视验收通过；自动化业务测试和 Release 打包结果独立成立。

真实系统通知横幅还依赖通知权限、专注模式和系统设置；跨 Space、多屏、授权后胶囊、macOS 14/15 兼容性沿用既有待测边界。本轮未变更这些权限。
