# Still 原生架构与阶段计划

## 范围和原则
Mac 自用菜单栏应用，无账号、联网、同步或服务端。项目建议 /Users/hzb/Developer/tools/Still。
SwiftUI 负责内容界面，AppKit 负责菜单栏和窗口协调。具体系统 API 与最低部署版本在检查 Xcode 后验证。
外观参数可扩展，布局用独立原生组件实现；不开发通用 JSON 布局解释器。

## 模块
- Domain：CountdownTask、TimerState、TimerEngine；只依赖 Foundation。注入时钟，纯逻辑不访问视图。
- Persistence：带 schemaVersion 的 Codable JSON 原子写入 Application Support/Still，损坏文件保留备份；用户偏好独立保存。每次用户操作和完成状态转换落盘，非每秒写入。
- Application：主线程 Store，拥有有序任务、偏好、操作入口；协调恢复、到时事件与持久化。
- Appearance：Palette（5 个稳定色位及派生文字/背景色）、固定 StyleTokens、固定 MaterialStyle；布局标识先只注册 HorizonGroup4。
- Presentation：TimerCard、TimerList、CreateTimer、Settings、Reminder。只显示 Store 状态并发送意图，不保存另一套倒计时。
- Platform：StatusItemController、PopoverCoordinator、ReminderCoordinator、生命周期/唤醒监听、通知授权。

## 时间与事件
运行任务保存 duration + deadline；暂停保存 remaining。刷新通过 deadline - now 计算，不依赖 tick 累减。
最早 deadline 驱动完成检查；视图刷新仅更新展示。唤醒、激活、启动再次核对，完成转换幂等。
用户主动修改系统时间按真实墙钟解释；此规则需在原生实现说明中保留。
启动先统一恢复所有过期任务、落盘完成状态，再发送一个恢复摘要。
待展示提醒独立排队；到时事件只产生一次。删除同步移除待展示提醒。

## 外观扩展
配色注册表：原样、苹果 II、谷歌 II；每套五色。任务保存 slotID，不保存颜色值。
按钮意图一致：toggle/restart/pin/delete/setColor。未来新卡片通过相同输入、输出接口接入。
玻璃用统一原生材质封装；HTML 的 CSS 模糊不是原生材质配方，需视觉样板校准。
提醒窗口可染色；系统通知采用系统样式，不能照搬 HTML toast。

## 阶段与验收
1. 定稿：本文、定稿需求、HTML。用户验收设置/返回/配色/提醒预览。
2. 环境与视觉样板：检查 Xcode、系统版本、签名；建立工程，实现菜单栏 + 弹窗 A + 一张固定样式卡片。用户确认原生材质、尺寸、字体。
3. 功能闭环：多任务、计时、暂停重启、排序删除、JSON 恢复。使用注入时钟测试暂停、越过 deadline、重复回调、启动多任务过期、色位分配；用户工作/休息试用。
4. 系统提醒：三等级、授权失败降级、唤醒恢复；检查多显示器和全屏应用的实际行为。用户操作通知权限并确认打断强度。
5. 设置与收尾：三配色、固定五色手动选色、持久化偏好、键盘导航、减少透明度/动态效果适配、性能检查。用户日常试用。

每阶段仅在验证相关行为后推进，不靠视觉截图证明后台计时或睡眠恢复。
当前没有创建 Xcode 工程、没有进行原生构建或部署。
