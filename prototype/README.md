## 使用与维护

HTML 无第三方运行依赖；预览方式见[工作流程](工作流程.md#html-预览)。每版维护定稿、方案存档和版本迭代三份资料，不再生成命名表与命名图。历史版本已有命名资料冻结保留。

从项目根目录运行 `node scripts/check_prototype.cjs v1.7` 检查原型脚本与核心规则。源码检查不代表浏览器视觉或原生验收通过。
