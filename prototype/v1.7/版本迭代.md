# v1.7 版本迭代

状态：用户已明确确认定稿。基线：[v1.6 定稿](../v1.6/留白-v1.6-定稿.html)。

最终选择：1:C 边缘胶囊；3:C2 刻环液玻；5:H 图标切换。首次外观默认自动跟随系统。第 2、4 项仅为评审模拟，不作为产品配置保留。

入口：[定稿](留白-v1.7-定稿.html) · [方案存档](留白-v1.7-方案存档.html)。

## 最终变化与验收条件

| 范围 | 变化 | 验收条件 |
|---|---|---|
| 全屏胶囊 | 全屏时补充单个 C2 边缘胶囊 | 桌面用菜单栏；全屏有运行任务才显示胶囊；与菜单栏选择同一任务。暂停、结束或删除当前任务后按既有规则接替，无任务隐藏。 |
| 胶囊进度环 | 透明中心、3px 描边进度环 | 开始为 0，半程 180 度，结束 360 度；结束后因任务完成切换或隐藏，不额外停留展示满环。 |
| 胶囊材质与展开 | 常驻标准液玻 | 无 5 秒沉浸切换；任务色半粗文字；悬停显示名称，移出收窄；键盘聚焦可展开。CSS 是光学近似，不是苹果原生折射。 |
| 胶囊操作 | 拖动与控制 | 移动超过 5px 才拖动；松开吸附左右边缘，保存高度与边；右侧锚定时收窄不漂移；点击打开原任务面板。 |
| 显示模式 | H 图标加文字三选一 | 白天／黑夜／自动互斥；全新数据默认自动；自动响应系统变化，手动模式不随系统改变；刷新保留选择。 |

沿用 v1.6 的任务新建、名称排序、单任务提醒及独立菜单栏任务选择规则。未新增原生产品实现。

## 清理与数据

定稿移除左侧方案区域、场景／背景比较控件、未采用胶囊及外观选项、方案存储与 5 秒沉浸逻辑。方案存档保留比较过程，默认定位最终选择。

定稿使用 `still-final-prototype-v1.7`，测试后缀 `-qa`；与草稿及 v1.6 隔离，不自动导入演示任务或读取原生任务文件。外观保存在任务数据的 prefs 中，缺失 autoTheme 时默认 true；胶囊位置保存在 prefs.capsulePosition。

## 全屏演示与平台边界

HTML 无法检测其他原生应用进入全屏。定稿响应浏览器 Fullscreen API 状态；亦可打开 [全屏演示](留白-v1.7-定稿.html?fullscreen=1) 查看胶囊，先启动任务再收起面板。这个 URL 参数只是原型演示，不是产品设置。普通打开定稿显示桌面状态。

原生开发需将其他应用全屏空间状态接入同一显示规则，并验证跨 Space 层级、多屏、自动外观、拖动位置恢复。原型尚不证明这些平台能力已完成。
