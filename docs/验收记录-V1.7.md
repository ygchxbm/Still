# v1.7 原生实现与验收

开发基准：[v1.7 版本迭代](../prototype/v1.7/版本迭代.md)及[定稿](../prototype/v1.7/留白-v1.7-定稿.html)。本记录区分实现、自动检查与实机验收；HTML 定稿不代表原生验收通过。

## 用户补充确认（2026-09-10）

- 全局只显示一个胶囊，跟随当前操作的全屏屏幕；切回普通桌面隐藏。
- 点击胶囊，在同一屏幕顶部菜单栏附近打开任务面板。
- 采用辅助功能授权方案。未授权时菜单栏、计时正常使用；设置提供“启用全屏胶囊”入口，授权后检测。不支持读取窗口全屏状态的应用不推测为全屏。

## 已实现

- C34–C37 / G24–G25：独立非激活胶囊窗口，与菜单栏共用当前运行任务；暂停、重置、删除及完成后按原规则接替，无任务隐藏。每秒更新全屏状态与时间，切换 Space 时另行刷新。
- 读取前台应用聚焦窗口的 `AXFullScreen`、位置和尺寸，按屏幕交集定位；不读取窗口内容，不用最大化尺寸猜测全屏。不支持该属性或权限失效时隐藏。
- 3pt 空心已用进度环，任务同色半粗文字；悬停或键盘聚焦展开名称；点击或辅助功能按压打开面板。移动超过 5pt 才拖动，松开吸附当前屏幕左右边缘，保存距顶部高度与边；屏幕变化后限位，右侧展开收窄保持右边缘。
- macOS 26 及以上使用 `NSGlassEffectView` 的标准材质；项目仍兼容 macOS 14/15，以原生视觉效果材质回退。没有静置 5 秒切换分支。
- E28–E31：图标加文字的白天／黑夜／自动三选一，默认自动；手动覆盖应用外观，自动交给系统响应。任务面板、设置、新建表单及提醒窗口取消强制浅色。
- 数据保留版本 2，以可选字段 `appearanceMode`、`capsulePosition` 扩展；旧数据缺失时默认自动及右上位置，不改任务、提醒和菜单栏选择规则。
- 构建版本更新为 1.7（17）。

## 胶囊修订（2026-09-10，用户确认）

用户反馈并确认以无描边磨砂玻璃替换标准液玻，深色模式使用稳定深色底。此项原生修订优先于此前定稿的材质描述，未修改已归档 HTML。

- 名称与时间统一为 14pt 半粗字体，使用相同纵向居中计算，与进度圆环中心对齐。
- 默认仅显示圆环和时间；名称只在鼠标悬停时显示，移开恢复。键盘焦点不再维持展开，仍支持键盘与辅助功能按压。
- 使用原生视觉效果磨砂底板和浅／深对比底色，不绘制外框；移除标准液玻的系统轮廓，禁用额外焦点环。
- 本轮编译与回归检查后仍需在真实全屏浅色背景下复核最终对齐、悬停与材质观感。

### 通透度修正

用户反馈对比底色遮盖玻璃透明效果。将深／浅底色透明度由 90%／88% 降为 20%／16%，保留 behind-window 原生磨砂效果；圆环仍仅描边，不填充中心。无外框、对齐及悬停行为不变。此调整需继续在浅深背景实机检查通透度与文字可读性。

### 胶囊独立浅色外观（用户确认）

胶囊窗口固定为 `NSAppearance.aqua`，始终使用浅色透明磨砂玻璃和浅色模式下的深色任务色，不随应用或系统的黑暗模式变化。其他窗口继续遵循白天／黑夜／自动设置。此条覆盖前述胶囊浅深底色切换要求。

### 近乎透明背景试用（用户授权，可恢复）

胶囊背景改为透明 NSView，移除系统磨砂，浅色覆盖层 alpha 从 0.16 降到 0.03。窗口继续固定浅色，文字、圆弧和底轨的不透明度保持原值。

恢复方式：背景换回 NSVisualEffectView（material = .hudWindow、blendingMode = .behindWindow、state = .active），浅色覆盖层 alpha 恢复 0.16。当前效果待用户试用确认。

### Dock 质感修订（用户明确期望）

用户反馈 3% 无磨砂底板看不到背景和液态玻璃，明确期望类似 Mac Dock。恢复 macOS 26+ NSGlassEffectView 的 regular 原生液玻，移除额外绘制的背景色，固定 aqua 浅色外观。旧系统使用 NSVisualEffectView 回退。保持内容对齐、悬停展开及禁用额外焦点环。系统材质自带边缘高光／轮廓，不另绘制描边；不承诺与 Dock 私有实现完全一致，最终质感需实机核对。此要求替代此前无磨砂 3% 底板试用。

### 通透液玻与外观跟随（用户确认）

胶囊 NSGlassEffectView.style 从 regular 改为 clear，取消固定 aqua，改为遵循应用白天／黑夜／自动设置。自动模式继承系统外观。此条覆盖此前固定浅色与 regular 材质要求；未添加额外背景覆盖色，旧系统磨砂回退保持不变。

### 圆环尺寸调整（用户确认）

保留当前 clear 原生液玻及系统焦点状态变化，不采用常驻高光模拟方案。参照用户截图，将圆环路径直径从 20pt 增至 26pt，描边仍为 3pt（外径由 23pt 增至 29pt）；胶囊高度仍为 44pt，内容起点和宽度增加 4pt，为圆环留出空间，右侧锚定规则不变。

## 设置页重构（2026-09-10）

以 v1.7 定稿设置页为视觉依据，重构为独立 SettingsView：

- 统一“显示模式”，保留白天／黑夜／自动图标文字选项及选中背景、轮廓。
- 配色为三行五色色点，通过背景高亮表示选中，移除可见勾号；辅助功能仍报告选中状态。
- 提醒选择使用原型完整文案及说明，提供整行“预览到时提醒”按钮，不改变各任务提醒强度。
- 全屏胶囊与通知授权以并排按钮放在底部；胶囊沿用授权行为，已授权时禁用并显示状态。退出留白为独立整行按钮。
- 统一圆角、间距和浅深色样式，设置内容滚动，保留自动保存说明。

已完成 15 项既有回归测试、Debug 构建；独立数据浅色预览确认页面结构、配色背景与无勾号样式。完整菜单交互、权限流程及深色视觉仍待复核，未以源码检查替代实机验收。

### 设置控件统一（用户反馈修订）

普通操作按钮、未选中的显示模式和提醒选择器共用同一套中性文字、透明浅底、边框及悬停色；显示模式与配色选中行共用强调色背景。退出按钮为红色文字、淡红底色。通过共享 SettingsControlSurface 管理颜色，避免各处独立透明度造成风格分裂。

所有可用设置按钮（含返回、配色行）及提醒选择器接入手形光标；禁用按钮保留箭头，避免暗示可以点击。构建及差异格式检查通过，最终浅深色与光标效果待实机复核。

### 胶囊光标反馈

悬停和按下未超过 5pt 阈值时显示手指；开始拖动后显示抓握手掌。松开并吸附边缘后按指针实际位置恢复手指或箭头；胶囊隐藏时清理拖动和光标状态。点击打开面板与拖动阈值不变。

### 胶囊手形稳定性修订

排查发现名称展开与每秒重复设置 frame 会更新跟踪/光标区域，原实现还在鼠标事件中不断 invalidateCursorRects。改为仅在几何变化时设置 frame，复用 inVisibleRect 跟踪区域，通过 cursorUpdate 和 mouseMoved 维护光标，并用实时指针坐标校验进入/退出事件。拖动移动窗口后再设置抓握手掌。需实机覆盖静止悬停跨计时更新、左右边缘展开收缩和拖动吸附。
