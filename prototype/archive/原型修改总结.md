## 1. 原型基础与新建任务

以用户提供的 `/Users/hzb/Documents/ChatGPT/原型小工具/留白-新建倒计时四方案_副本.html` 为基础，沿用玻璃背景、配色、图标、322px 任务面板和水平分段进度条，生成可独立打开的单文件 HTML。

- 名称可留空，最多 40 字符；时长以分钟输入，有效范围 1 秒至 1440 分钟；快捷值为 5、10、25、40、60 分钟。
- 确认新建保存为“待开始”，由用户点击开始后计时；取消不创建。
- 重置恢复任务当前总时长，进入待开始，不自动启动。若任务已延长为 5 分钟，重置恢复的是这段 5 分钟。

## 2. 菜单栏任务与排序：已定稿

最初加入“修改前／修改后”对比；用户已选择“修改后”，当前移除了该组标题、选项及旧的首项显示分支。

菜单栏显示对象与列表顺序分开管理：

| 触发情况 | 当前规则 |
|---|---|
| 无运行任务 | 显示“留白”，进度归零 |
| 第一项通过开始／继续／再来进入运行 | 成为菜单栏当前任务 |
| 当前任务仍运行，又启动另一项 | 保持当前任务，不抢占 |
| 当前任务暂停、完成、重置或删除 | 切换到其他仍运行、且本轮开始／继续时间最早的任务 |
| 原任务暂停后又继续 | 不抢回已由其他运行任务占用的菜单栏 |
| 手动点击“显示到菜单栏” | 指定该运行任务，列表顺序不变 |
| 拖动或键盘调整列表顺序 | 仅更新顺序，不切换菜单栏任务 |

C06 原置顶按钮改为“显示到菜单栏”，图标为带顶部栏的小窗口。只有运行任务可点击，其他状态置灰；当前显示任务具有选中状态。菜单栏时间、进度及任务状态中的“· 菜单栏”指向同一任务。

实现保存当前任务 ID 与本轮运行时间；没有历史运行时间的旧演示任务，首次迁移时按现有顺序补齐。

## 3. 单任务提醒强度：已定稿

提醒由全局配置改为每个任务独立保存。

- C05 工具区顺序：显示到菜单栏 → 提醒强度 → 删除 → 改色。
- 新任务默认轻提醒；旧演示任务缺少提醒字段时补为轻提醒。
- 点击提醒强度按钮，按“轻提醒 → 醒目提醒 → 强打断 → 轻提醒”循环。
- 悬停提示当前强度及点击切换；真实到时事件读取该任务的强度。
- 已生成的提醒事件保留当时等级；以后切换任务等级不修改正在展示的提醒。
- 初期提供 A 铃铛、B 强度条、C 提醒范围三组图标。用户已定稿 A 铃铛，移除三组切换入口及 B／C 图标分支。
- A 的三档表现：基础铃铛、带声波铃铛、带强调标记铃铛。

设置页不再设置全局任务提醒强度；原等级选择器改作“提醒效果预览”，可临时选择三档并点击预览，不改变任务强度。新建说明相应改为“轻提醒／可在任务工具区调整提醒强度”。

轻提醒为页面右上角浮层，醒目提醒为页面中央卡片，强打断覆盖页面；不申请系统通知权限，不创建原生多屏窗口。预览中的延长按钮只结束预览，不修改任务。

## 4. 拖动排序：功能已加入，外观仍可选

没有加入编辑模式。当前提供五个方案，全部保留，尚未选定最终外观：

| 选项 | 图标与位置 | 方案值 |
|---|---|---|
| 原方案 · 六点把手 | 任务名称左侧，原图标与位置 | original |
| 方案 1 · 三横线 | 只换图标，位置与点击范围不变 | lines |
| 方案 2 · 顶部点列 | 横向四点，卡片顶部中央 | top |
| 方案 3 · 侧边上下箭头 | 上下箭头，卡片左侧居中 | edge |
| 方案 4 · 名称区拖动 | 不显示拖动图标，名称、状态及所在区域空白处可拖动 | name |

首次没有保存选项时使用原六点方案；已有选择会恢复。切换外观不改变任务顺序、菜单栏任务或提醒等级。

共有交互：移动距离超过约 5px 后开始拖动；源卡片降低透明度，目标位置显示插入线；靠近列表上下边缘自动滚动；松手保存；Esc、指针取消或窗口失焦取消拖动。拖动区域聚焦后也可通过上下方向键排序并保存。只有一项任务时禁用排序；新建表单不参与排序。

名称区方案的工具按钮、时间数字和底部计时按钮不作为拖动区域。按用户反馈，已移除名称区获得焦点时的边框；排序目标插入线保持不变。当前源卡片反馈是降低透明度，没有实现独立跟随鼠标的悬浮卡片。

## 6. 数据与文件范围

普通原型使用浏览器 localStorage 键 `still-project-prototype-v1`；URL 带 `?qa=1` 时使用 `still-project-prototype-v1-qa`。不同来源（如 file 与 HTTP）下的浏览器存储不能假定互通。

保存任务、顺序、色位、配色、单任务提醒、菜单栏当前任务及拖动方案。数据不访问原生 `state.json`，也不覆盖参考原型的存储键。首次提供两个演示任务。
