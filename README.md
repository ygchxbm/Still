# Still · 留白

Mac 原生菜单栏倒计时工具。支持多任务计时、三档提醒、全屏边缘胶囊与白天／黑夜／自动外观，无账号和第三方依赖。

## 构建与运行

需要 macOS 14 或更新系统，以及支持项目 API 的 Xcode / Swift 工具链。当前构建验证环境为 macOS 27 / Xcode 27；macOS 14/15 兼容性仍待实机验收。

```sh
./build.sh
open build/Still.app
```

Xcode 可直接打开 `Package.swift`。`./build.sh` 默认生成 Debug 应用；日常试用优化后的构建可运行 `./build.sh release`。两种配置均输出 `build/Still.app`，并校验应用信息和本地临时签名；不会启动应用。正式分发所需的开发者签名与公证流程尚未配置。

## 使用

- 点击菜单栏打开任务面板，在列表底部新建倒计时，点击开始后计时。
- 支持暂停、继续、重置、拖动排序、改色和删除；菜单栏任务可单独指定。
- 每张卡片的铃铛按钮切换轻提醒、醒目提醒、强打断；轻提醒仅发送无声系统通知，设置页可预览三种提醒。
- 设置中可开启「登录时自动启动」；默认不注册，开启后登录时在菜单栏后台运行。需要系统批准时按设置页提示处理。
- 设置中选择配色与显示模式，主动允许系统通知或启用全屏胶囊。
- 胶囊需要辅助功能授权，与菜单栏显示同一运行任务，可拖到屏幕左右边缘并点击打开面板。

## 数据与边界

数据保存在 `~/Library/Application Support/Still/state.json`，包括任务、排序、配色和外观偏好。原子写入；版本 1 数据迁移前保留 `state.json.v1-backup`，损坏或未知版本数据不会覆盖。

关闭面板不暂停计时。退出或休眠期间不保证当场提醒，重新打开或唤醒后补发轻提醒摘要。系统通知受授权、专注模式和系统设置影响。辅助功能未授权时仍可使用菜单栏计时。
