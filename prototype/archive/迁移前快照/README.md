## 当前版本

- 沿用参考原型的玻璃背景、322px 任务面板、五色任务卡片及水平分段进度条。
- 新建采用 B 原位展开／轻量清单／自动配色；确认后待开始。支持开始、暂停、继续、再来、重置、删除和改色。
- 菜单栏独立选择运行任务；“显示到菜单栏”替代置顶，只指定显示对象，不改变列表顺序。无运行任务显示“留白”。这部分已定稿，无修改前后切换。
- 每个任务独立设置提醒强度，按钮位于菜单栏指定与删除之间，点击循环三档；固定 A 铃铛图标。设置页等级选择仅用于预览。
- 交互方案面板与任务面板左右并排、内部滚动；极窄视口保持并排，可横向滚动查看。

## 拖动方案：仍可切换

| 选项 | 拖动区域 |
|---|---|
| 原方案 · 六点把手 | 名称左侧 |
| 方案 1 · 三横线 | 与原方案相同位置，只换图标 |
| 方案 2 · 顶部点列 | 卡片顶部中央 |
| 方案 3 · 侧边上下箭头 | 卡片左侧居中 |
| 方案 4 · 名称区拖动 | 名称、状态及所在区域空白处，不显示图标 |

首次默认原六点，后续恢复保存的选择；五项尚未最终定稿。拖动超过约 5px 开始排序，支持边缘自动滚动、松手保存、Esc 取消及聚焦后上下方向键排序。单项任务禁用排序。名称区的焦点边框已移除，目标插入线保留。

## 数据与模拟范围

- 普通数据键：`still-project-prototype-v1`；URL 带 `?qa=1` 使用 `still-project-prototype-v1-qa`。
- 数据保存在当前浏览器来源的 localStorage 中，首次提供两个演示任务；不同来源的数据不保证互通。
- 不读取原生应用任务文件，不覆盖参考原型数据。
- 三档提醒均为页面内模拟，不申请系统通知权限，不创建原生多屏窗口，也不提供真实退出应用功能。
