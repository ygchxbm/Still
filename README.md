# Still · 留白

macOS 原生倒计时，当前交付为第一阶段视觉样板。

## 运行

在此目录执行 `./build.sh`，然后打开 `build/Still.app`。点击菜单栏时间打开面板；右上角齿轮进入设置，设置底部可退出应用。再次打开应用也可以显示面板。

用 Xcode 打开 `Package.swift` 可浏览和编辑工程。当前使用 Swift Package，无第三方依赖；应用打包及本地签名由 build.sh 完成。

## 已实现

- AppKit 菜单栏与原生 NSPopover，SwiftUI 卡片和材质。
- 固定水平时间轴布局，置顶 → 删除 → 改色按钮。
- 三套五色配色、任务改色入口、设置入口。
- 内存中的新建、暂停、继续、重启、置顶与删除。
- 基于截止时间计算剩余时间；菜单栏每秒绘制第一项任务的时间和同色增长进度。

## 尚未实现

- 三个等级的正式到时提醒；当前预览仅为占位说明。

## 结构

- Sources/Still/Model.swift：任务数据与内存操作、配色定义。
- Sources/Still/Views.swift：弹窗、卡片、设置与创建表单。
- Sources/Still/StillApp.swift：应用生命周期、菜单栏、原生弹窗。
- docs：已确认需求和后续分层架构计划。

后续实现时将配色、存储及计时领域分别拆分；此阶段优先验证原生视觉。
